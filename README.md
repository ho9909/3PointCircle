# MFC 3-Point Circumcircle Drawing Program

마우스로 입력한 3개의 점을 모두 지나는 정원(외접원)을 계산하여 그리는  
MFC(Dialog 기반) 그래픽 프로그램입니다.  

드래그를 통한 실시간 재계산, 깜빡임 방지 더블버퍼링,  
작업자 스레드를 이용한 랜덤 이동 애니메이션까지 구현하여  
**UI 응답성과 안정성**을 함께 고려한 프로젝트입니다.

---

## 📌 주요 기능

### 1. 3점 입력 및 정원(외접원) 생성
- 마우스 좌클릭으로 최대 3개의 점 입력
- 세 번째 점 입력 시, 세 점을 모두 지나는 정원 자동 생성
- 세 점이 일직선인 경우 예외 처리(원 생성 불가 안내)

### 2. 점 및 정원 그리기
- 클릭 지점은 채워진 원으로 표시
- 정원은 내부가 비어 있는 테두리 원으로 표시
- 사용자 입력을 통해
  - 점 반지름
  - 정원 테두리 두께
  를 실시간 조절 가능

### 3. 드래그 기반 실시간 재계산
- 이미 생성된 점을 클릭 후 드래그 가능
- 드래그 중에도 정원이 실시간으로 재계산 및 갱신
- UI 영역을 침범하지 않도록 그리기 허용 영역 자동 계산 및 경계 보정

### 4. 랜덤 이동 애니메이션 (작업자 스레드)
- 작업자 스레드(`CWinThread`)를 사용하여 랜덤 좌표 생성
- UI 스레드와는 PostMessage 기반 비동기 통신
- 랜덤 이동 중에도 UI 멈춤 없이 정상 동작
- Atomic 변수를 이용한 안전한 스레드 제어

### 5. 깜빡임 방지 및 성능 개선
- `OnEraseBkgnd` 무효화
- Memory DC + Bitmap을 활용한 더블버퍼링
- `InvalidateRect`를 이용한 부분 갱신 렌더링

### 6. 안전한 종료 및 Reset 처리
- 랜덤 이동 중 Reset / 창 종료 시에도 크래시 없이 정상 종료
- 스레드 종료 대기 및 메시지 큐에 남은 Payload 메모리 정리

## 🧠 핵심 구현 설명

### ● 외접원 계산
세 점의 좌표를 이용해 행렬식을 기반으로 중심 좌표를 계산하고,  
중심과 한 점 사이의 거리를 반지름으로 사용합니다.  
세 점이 일직선인 경우 분모가 0에 가까워지므로 예외 처리합니다.

### ● 드래그 & 실시간 갱신
- 히트 테스트로 선택된 점을 식별
- 마우스 이동 중 좌표를 갱신
- 정원 재계산 → 부분 영역만 다시 그리기

### ● 스레드 안전 설계
- 작업자 스레드는 좌표 계산만 수행
- UI 변경은 반드시 메인 스레드에서 처리
- `std::atomic<bool>`을 이용해 중단 신호 전달
- 사용자 정의 메시지를 통해 데이터 전달
